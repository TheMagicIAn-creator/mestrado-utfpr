## 1. Justificativa da Escolha do Isolation Forest para Detecção de Anomalias

O **Isolation Forest** é uma técnica de detecção de anomalias que opera isolando as observações anômalas, em vez de perfilar as observações normais. Ele constrói árvores de decisão (como uma Random Forest, mas com um objetivo diferente) de forma que as anomalias, por serem "poucas e diferentes", tendem a ser isoladas em caminhos mais curtos nas árvores.

**Vantagens para o nosso contexto:**
*   **Não supervisionado:** Não requer dados rotulados de "falha" ou "normal", o que é comum em cenários de manutenção preditiva onde falhas são raras.
*   **Eficiência:** Funciona bem com grandes volumes de dados e alta dimensionalidade.
*   **Interpretabilidade (relativa):** Embora não seja tão transparente quanto uma árvore de decisão única, a lógica de "isolamento" é mais fácil de compreender do que a de algumas redes neurais profundas.
*   **Adequado para iniciantes:** A implementação em `scikit-learn` é direta e os parâmetros são razoavelmente intuitivos.

**Conexão com a literatura e o mestrado:**
A detecção de anomalias é o primeiro passo para a **análise preditiva de falhas**. Uma vez que uma anomalia é detectada, podemos investigar se ela corresponde a um modo de falha conhecido, como os que seriam identificados por uma **FMEA (Failure Mode and Effects Analysis)** ou **FMECA (Failure Mode, Effects and Criticality Analysis)**. A FMEA, conforme descrito por Sakurada (1998) em "Criticality Analysis" (Trechos 1, 2, 4, 5, 6, 13, 14) e Carpinetti (2016) em "Fmea Ingles Failure Mode Effect" (Trechos 8, 9, 10), é fundamental para entender os **modos de falha potenciais**, seus **efeitos** e **causas**, e a **severidade** e **ocorrência** associadas. Essa análise nos ajuda a definir o que *procurar* como anomalia e a priorizar as ações.

## 2. Exemplo de Código Python para Detecção de Anomalias com Isolation Forest

Este código simulará dados de um inversor fotovoltaico e aplicará o Isolation Forest para identificar pontos anômalos.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.ensemble import IsolationForest
from sklearn.preprocessing import StandardScaler
import seaborn as sns

# --- 1. Geração de Dados Sintéticos (Simulação de Sinais CA de Inversor) ---
# Conforme o contexto, usaremos Corrente CA, Tensão CA, Temperatura, Potência Ativa.
# Rodolfo, lembre-se que para o seu mestrado, você usará os CSVs de laboratório
# ou datasets do Kaggle. Aqui, estamos apenas simulando para demonstrar o conceito.

np.random.seed(42) # Para reprodutibilidade

# Gerar dados "normais" para 1000 amostras
n_samples = 1000
data_normal = pd.DataFrame({
    'Corrente_CA_RMS': np.random.normal(loc=10, scale=0.5, size=n_samples), # Corrente RMS em Amperes
    'Tensao_CA_RMS': np.random.normal(loc=220, scale=2, size=n_samples),   # Tensão RMS em Volts
    'Temperatura_IGBT': np.random.normal(loc=45, scale=3, size=n_samples), # Temperatura em °C
    'Potencia_Ativa': np.random.normal(loc=2200, scale=100, size=n_samples) # Potência em Watts
})

# Introduzir algumas anomalias (simulando falhas ou comportamentos atípicos)
# Exemplo 1: Pico de corrente e temperatura (sobrecarga ou falha de IGBT)
anomalia_1 = pd.DataFrame({
    'Corrente_CA_RMS': [15, 16, 14.5],
    'Tensao_CA_RMS': [210, 205, 212],
    'Temperatura_IGBT': [70, 75, 68],
    'Potencia_Ativa': [3000, 3200, 2900]
})

# Exemplo 2: Queda de tensão e potência (problema na rede ou no inversor)
anomalia_2 = pd.DataFrame({
    'Corrente_CA_RMS': [8, 7.5, 8.2],
    'Tensao_CA_RMS': [180, 175, 185],
    'Temperatura_IGBT': [40, 39, 41],
    'Potencia_Ativa': [1500, 1400, 1600]
})

# Exemplo 3: Leitura de sensor errônea (temperatura muito baixa)
anomalia_3 = pd.DataFrame({
    'Corrente_CA_RMS': [10.1, 9.9],
    'Tensao_CA_RMS': [220.5, 219.8],
    'Temperatura_IGBT': [5, 8], # Anomalia aqui
    'Potencia_Ativa': [2250, 2180]
})

# Concatenar todos os dados
data = pd.concat([data_normal, anomalia_1, anomalia_2, anomalia_3], ignore_index=True)

print(f"Total de amostras geradas: {len(data)}")
print("\nPrimeiras 5 linhas dos dados sintéticos:")
print(data.head())

# --- 2. Pré-processamento dos Dados ---
# É uma boa prática escalar os dados para que todas as features tenham a mesma importância.
# O Isolation Forest não é tão sensível à escala quanto outros algoritmos baseados em distância,
# mas a padronização pode ajudar na consistência.

scaler = StandardScaler()
data_scaled = scaler.fit_transform(data)
data_scaled_df = pd.DataFrame(data_scaled, columns=data.columns)

print("\nPrimeiras 5 linhas dos dados escalados:")
print(data_scaled_df.head())

# --- 3. Aplicação do Isolation Forest ---
# O parâmetro 'contamination' é a proporção esperada de anomalias nos dados.
# É um hiperparâmetro importante e muitas vezes requer ajuste.
# Para este exemplo, vamos assumir uma pequena porcentagem.
# 'random_state' garante que os resultados sejam os mesmos a cada execução.

model = IsolationForest(n_estimators=100, contamination=0.02, random_state=42)
# n_estimators: número de árvores na floresta. Mais árvores geralmente levam a melhores resultados, mas aumentam o tempo de computação.
# contamination: a proporção de outliers nos dados. É uma estimativa. Se você não tem ideia, pode começar com um valor pequeno (e.g., 0.01).

# Treinar o modelo e fazer as previsões
# O método fit_predict retorna -1 para anomalias e 1 para pontos normais.
data['anomaly_score'] = model.decision_function(data_scaled_df) # Pontuação de decisão: quanto menor, mais anômalo.
data['is_anomaly'] = model.fit_predict(data_scaled_df) # -1 para anomalia, 1 para normal

# --- 4. Análise e Visualização dos Resultados ---

print("\nContagem de pontos normais e anômalos:")
print(data['is_anomaly'].value_counts())

# Filtrar as anomalias
anomalies = data[data['is_anomaly'] == -1]
normal_points = data[data['is_anomaly'] == 1]

print(f"\nNúmero de anomalias detectadas: {len(anomalies)}")
print("\nDetalhes das anomalias detectadas:")
print(anomalies)

# Visualização (exemplo com duas features para facilitar a plotagem)
plt.figure(figsize=(12, 8))
sns.scatterplot(x='Corrente_CA_RMS', y='Temperatura_IGBT', data=normal_points, color='blue', label='Normal', alpha=0.6)
sns.scatterplot(x='Corrente_CA_RMS', y='Temperatura_IGBT', data=anomalies, color='red', label='Anomalia', s=100, marker='X')
plt.title('Detecção de Anomalias em Dados de Inversor com Isolation Forest')
plt.xlabel('Corrente CA RMS (A)')
plt.ylabel('Temperatura IGBT (°C)')
plt.legend()
plt.grid(True)
plt.show()

# Visualização da pontuação de anomalia
plt.figure(figsize=(12, 6))
sns.histplot(data['anomaly_score'], bins=50, kde=True)
plt.axvline(x=data['anomaly_score'].min(), color='red', linestyle='--', label='Menor pontuação (mais anômalo)')
plt.title('Distribuição das Pontuações de Anomalia')
plt.xlabel('Pontuação de Anomalia (quanto menor, mais anômalo)')
plt.ylabel('Frequência')
plt.legend()
plt.grid(True)
plt.show()

# --- 5. Interpretação e Próximos Passos ---
# Rodolfo, aqui você pode analisar as características das anomalias detectadas.
# Por exemplo, quais features tiveram os valores mais extremos nas amostras classificadas como anomalias?
# Isso pode te dar insights sobre os modos de falha.

print("\nAnálise das características das anomalias:")
print(anomalies.describe())

# Comparar com os dados normais
print("\nAnálise das características dos pontos normais:")
print(normal_points.describe())

# Você pode ver que a média e o desvio padrão das anomalias são significativamente diferentes
# dos pontos normais para as features que foram manipuladas (Corrente, Temperatura, Tensão, Potência).
# Isso indica que o Isolation Forest conseguiu capturar esses desvios.
```

1.  **Geração de Dados Sintéticos:**
    *   Criamos um `DataFrame` (`data_normal`) com 1000 amostras de `Corrente_CA_RMS`, `Tensao_CA_RMS`, `Temperatura_IGBT` e `Potencia_Ativa`, usando distribuições normais para simular o comportamento usual de um inversor.
    *   Em seguida, adicionamos pequenos conjuntos de dados (`anomalia_1`, `anomalia_2`, `anomalia_3`) com valores atípicos para simular diferentes tipos de falhas ou comportamentos anômalos (e.g., sobrecarga, queda de tensão, erro de sensor).

    *   `model.decision_function()` retorna uma pontuação para cada amostra: quanto menor a pontuação, mais anômala a amostra é considerada.
    *   `model.fit_predict()` treina o modelo e classifica cada amostra como normal (`1`) ou anômala (`-1`).

    *   Um histograma das pontuações de anomalia mostra a distribuição dessas pontuações, onde valores mais à esquerda (menores) indicam maior probabilidade de anomalia.

### 1.1. `UserWarning: X has feature names, but IsolationForest was fitted without feature names`

Este é um **aviso** (`UserWarning`), não um erro que interrompe a execução, mas é importante. Ele ocorre porque o `IsolationForest` foi treinado (`fit`) com um formato de dados (provavelmente um array NumPy sem nomes de colunas explícitos) e, posteriormente, você está tentando usar o método `decision_function` (ou `score_samples`) com um `DataFrame` do pandas que possui nomes de colunas (`feature names`).

**Implicação:** Embora o `scikit-learn` geralmente lide bem com isso, é uma boa prática garantir consistência. Se a ordem das colunas no seu `DataFrame` de teste (`data_scaled_df`) for diferente da ordem das colunas usadas no treinamento, o modelo pode fazer previsões incorretas.

### 1.2. `sklearn.exceptions.NotFittedError: This IsolationForest instance is not fitted yet. Call 'fit' with appropriate arguments before using this estimator.`

Este é o **erro crítico** que está impedindo a execução do seu código. Ele é bastante explícito: a instância do `IsolationForest` (`model`) não foi treinada (ou "ajustada") antes de você tentar usar o método `decision_function`.

**Implicação:** Modelos de Machine Learning, como o `IsolationForest`, precisam aprender os padrões dos dados antes de poderem fazer previsões ou calcular pontuações. O método `fit()` é responsável por esse processo de aprendizado. Sem ele, o modelo não tem conhecimento para operar.

## 2. Solução para os Erros

A solução principal é garantir que o modelo seja **treinado** (`fit`) antes de ser usado para calcular pontuações de anomalia. Além disso, podemos ajustar a forma como os dados são passados para o modelo para resolver o `UserWarning`.

### 2.1. Corrigindo o `NotFittedError`

Você precisa chamar o método `fit()` na sua instância do `IsolationForest` (`model`) antes de chamar `decision_function()`. O `IsolationForest` é um algoritmo de detecção de anomalias não supervisionado, o que significa que ele aprende a partir de dados "normais" (sem anomalias explícitas rotuladas) para identificar o que é anômalo.

**Passos:**

1.  **Instancie** o `IsolationForest`.
2.  **Treine** o modelo com seus dados de treinamento (que devem representar o comportamento normal do sistema).
3.  **Use** o modelo para calcular as pontuações de anomalia.

### 2.2. Lidando com o `UserWarning`

Para evitar o aviso e garantir consistência, você pode converter seu `DataFrame` para um array NumPy antes de passá-lo para o `fit()` e `decision_function()`, ou garantir que os nomes das colunas sejam consistentes. Para iniciantes em ML, usar `values` para obter o array NumPy é uma abordagem mais simples.

### Exemplo de Código Corrigido

Considerando que `data_scaled_df` é o seu `DataFrame` com os dados já pré-processados e escalados, o fluxo correto seria:

```python
import pandas as pd
from sklearn.ensemble import IsolationForest
from sklearn.preprocessing import StandardScaler

# Supondo que 'data' é o seu DataFrame original e você já fez algum pré-processamento
# Exemplo de dados (substitua pelos seus dados reais)
# data = pd.DataFrame(...)

# 1. Pré-processamento e Escalonamento (se ainda não foi feito)
# Identifique as colunas numéricas que serão usadas para a detecção de anomalias
features = ['Corrente CA', 'Tensão CA', 'Temperatura', 'Potência ativa/reativa'] # Exemplo, ajuste conforme seu dataset

# Crie uma cópia para evitar SettingWithCopyWarning
data_for_model = data[features].copy()

# Instancie o escalador
scaler = StandardScaler()

# Ajuste e transforme os dados
data_scaled = scaler.fit_transform(data_for_model)
data_scaled_df = pd.DataFrame(data_scaled, columns=features, index=data_for_model.index)

# 2. Instanciar o modelo IsolationForest
# Ajuste os parâmetros como contamination, random_state conforme necessário
# contamination: proporção esperada de anomalias nos dados (um valor entre 0 e 0.5)
model = IsolationForest(random_state=42, contamination=0.01) # Exemplo: 1% de anomalias esperadas

# 3. Treinar o modelo (FIT)
# O IsolationForest é treinado com os próprios dados que você quer analisar,
# pois ele é um método não supervisionado.
# Para evitar o UserWarning, passamos os valores do DataFrame (array NumPy).
model.fit(data_scaled_df.values)

# 4. Calcular a pontuação de anomalia (DECISION_FUNCTION)
# Novamente, passamos os valores do DataFrame.
data_scaled_df['anomaly_score'] = model.decision_function(data_scaled_df.values)

# 5. Classificar as anomalias (opcional, mas útil para visualização)
# O IsolationForest atribui -1 para anomalias e 1 para pontos normais.
data_scaled_df['anomaly'] = model.predict(data_scaled_df.values)

# Agora você pode analisar 'anomaly_score' e 'anomaly'
print(data_scaled_df.head())
```

**Explicação do `contamination`:** O parâmetro `contamination` é crucial para o `IsolationForest`. Ele representa a proporção esperada de anomalias em seu conjunto de dados. Se você não tem uma estimativa clara, pode começar com um valor pequeno (e.g., 0.01 para 1%) e ajustá-lo com base na análise dos resultados e no conhecimento do domínio.
