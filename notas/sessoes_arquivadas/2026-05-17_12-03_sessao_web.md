## 1. Fundamentos para o Cálculo Preditivo de Falhas em IGBTs

A predição de falhas em IGBTs envolve monitorar parâmetros elétricos e térmicos que indicam sua degradação ao longo do tempo. Os IGBTs são componentes críticos no lado CA (e também CC, dependendo da arquitetura) dos inversores, e suas falhas podem ser catastróficas.

> Conforme Sakurada Eduardo Yuji Tecnicas Analise (1998), ao pensar em modos de falha, "deve-se pensar na perda da função do sistema – uma falha específica." Para IGBTs, isso pode ser um curto-circuito, circuito aberto, ou degradação de parâmetros que levam a um desempenho inadequado.

Os dados que você mencionou (Corrente CA, Tensão CA, Temperatura, Potência ativa/reativa) são excelentes pontos de partida. A partir deles, podemos extrair **características (features)** que servirão de entrada para os modelos de Machine Learning.

### 1.1. Modos de Falha Típicos em IGBTs e Sinais Associados

Para um IGBT, alguns modos de falha e seus sinais potenciais incluem:

*   **Degradação da solda/conexões:** Aumento da resistência de condução, aumento da temperatura da junção, variações na tensão de saturação (Vce_sat). Pode ser detectado por variações na **temperatura** e **perdas de potência** (eficiência).
*   **Degradação do encapsulamento:** Aumento da resistência térmica, levando a superaquecimento. Detectável por **temperatura** elevada e desvios de **corrente/tensão**.
*   **Falha do gate driver:** Operação incorreta do IGBT (ligar/desligar), resultando em sobrecorrentes ou sobretensões. Pode ser visto em **distorções de corrente/tensão** (THD), **surtos de corrente** ou **variações na frequência de chaveamento**.

### 1.2. Abordagens de Machine Learning

Conforme o perfil do agente e a literatura, podemos usar:

*   **Classificação:** Para detectar a presença de uma falha (binário: "normal" vs. "falha") ou classificar o tipo de falha. Modelos como **Random Forest**, **XGBoost** e **LightGBM** são eficazes (Ajay Narayanan, 2023; Memória 2).
*   **Regressão:** Para estimar a **RUL (Remaining Useful Life)**, ou seja, quanto tempo o componente ainda tem antes de falhar. Modelos como **Random Forest Regressor**, **LSTM** (para séries temporais) ou **Processos Gaussianos** (para incerteza) são adequados.
*   **Detecção de Anomalias:** Para identificar comportamentos incomuns que podem ser precursores de falhas, sem a necessidade de dados de falha rotulados. **Autoencoders** e **Isolation Forest** são bons candidatos (Jan Francisti, 2025; Forest Framework, 2026).

## 3. Exemplo de Código Python: Detecção de Falhas em IGBTs

Este exemplo focará na **detecção de anomalias** e **classificação de falhas** usando dados simulados.

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier, IsolationForest
from sklearn.metrics import classification_report, accuracy_score, roc_auc_score
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt
import seaborn as sns
import shap # Para interpretabilidade

# Configurações para visualização
sns.set_style("whitegrid")

print("Al IAdo: Iniciando o pipeline de detecção de falhas em IGBTs.")

## 3.1. Geração de Dados Sintéticos (Placeholder)
# Em um cenário real, você carregaria seus CSVs de 'dados/' aqui.
# Para este exemplo, vamos simular dados de corrente, tensão e temperatura
# para um IGBT, com alguns padrões de degradação e falha.

np.random.seed(42)
n_samples = 2000 # Número de amostras de tempo
time = np.arange(n_samples)

# Sinais normais
current_normal = 10 * np.sin(2 * np.pi * 60 * time / 1000) + np.random.normal(0, 0.1, n_samples)
voltage_normal = 220 * np.sin(2 * np.pi * 60 * time / 1000 + np.pi/2) + np.random.normal(0, 0.5, n_samples)
temp_normal = 50 + 5 * np.sin(2 * np.pi * 0.1 * time / 1000) + np.random.normal(0, 1, n_samples)

# Simulação de degradação e falha de IGBT
# Ex: Aumento da temperatura, distorção de corrente/tensão
# Vamos introduzir uma falha a partir da amostra 1500
fault_start_idx = 1500

# Degradação: Aumento gradual da temperatura
temp_degradation = np.zeros(n_samples)
temp_degradation[fault_start_idx:] = np.linspace(0, 20, n_samples - fault_start_idx) # Aumento de 20 graus

# Falha: Aumento de THD na corrente, queda de tensão
current_fault = np.zeros(n_samples)
voltage_fault = np.zeros(n_samples)

# Simular distorção harmônica na corrente após a falha
current_fault[fault_start_idx:] = 2 * np.sin(2 * np.pi * 180 * time[fault_start_idx:] / 1000) # 3ª harmônica
voltage_fault[fault_start_idx:] = -10 * np.sin(2 * np.pi * 60 * time[fault_start_idx:] / 1000) # Queda de tensão

# Combinar sinais
current = current_normal + current_fault
voltage = voltage_normal + voltage_fault
temperature = temp_normal + temp_degradation

# Criar rótulo de falha (0: normal, 1: falha)
labels = np.zeros(n_samples)
labels[fault_start_idx:] = 1

# Criar DataFrame
data = pd.DataFrame({
    'time': time,
    'current': current,
    'voltage': voltage,
    'temperature': temperature,
    'label': labels
})

print(f"Dados sintéticos gerados com {n_samples} amostras. {labels.sum()} amostras rotuladas como falha.")

## 3.2. Engenharia de Características (Feature Engineering)
# Extrair características relevantes de sinais elétricos e temperatura.
# Para sinais CA, RMS, THD, média, desvio padrão são cruciais.

# Usaremos uma janela deslizante para calcular características
window_size = 100 # Amostras por janela
features = []
window_labels = []

for i in range(0, n_samples - window_size + 1, window_size // 2): # Janela com sobreposição
    window_data = data.iloc[i : i + window_size]
    
    # Características da Corrente
    rms_current = np.sqrt(np.mean(window_data['current']**2))
    mean_current = np.mean(window_data['current'])
    std_current = np.std(window_data['current'])
    
    # Características da Tensão
    rms_voltage = np.sqrt(np.mean(window_data['voltage']**2))
    mean_voltage = np.mean(window_data['voltage'])
    std_voltage = np.std(window_data['voltage'])

    # Características da Temperatura
    mean_temp = np.mean(window_data['temperature'])
    std_temp = np.std(window_data['temperature'])
    max_temp = np.max(window_data['temperature'])
    
    # (Opcional) THD - Requer FFT, que é mais complexo para simular aqui diretamente
    # thd_current = calculate_thd(window_data['current']) # Função a ser implementada
    
    features.append([
        rms_current, mean_current, std_current,
        rms_voltage, mean_voltage, std_voltage,
        mean_temp, std_temp, max_temp
    ])
    
    # O rótulo da janela é 1 se houver qualquer falha na janela, 0 caso contrário
    window_labels.append(1 if window_data['label'].sum() > 0 else 0)

feature_names = [
    'RMS_Current', 'Mean_Current', 'Std_Current',
    'RMS_Voltage', 'Mean_Voltage', 'Std_Voltage',
    'Mean_Temperature', 'Std_Temperature', 'Max_Temperature'
]
X = pd.DataFrame(features, columns=feature_names)
y = np.array(window_labels)

print(f"Engenharia de características concluída. {X.shape[0]} janelas de dados geradas.")

## 3.3. Pré-processamento de Dados
# Normalização e divisão em conjuntos de treino e teste.

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, test_size=0.3, random_state=42, stratify=y)

print(f"Dados divididos: Treino ({X_train.shape[0]} amostras), Teste ({X_test.shape[0]} amostras).")

## 3.4. Modelagem e Treinamento
### 3.4.1. Detecção de Anomalias com Isolation Forest
# Útil para identificar desvios do comportamento normal sem rótulos de falha explícitos.
# Treinamos apenas com dados "normais" (label=0) para aprender o padrão normal.

X_train_normal = X_train[y_train == 0]

isolation_forest = IsolationForest(contamination=0.05, random_state=42) # 'contamination' é a proporção esperada de anomalias
isolation_forest.fit(X_train_normal)

# Prever anomalias no conjunto de teste (-1 para anomalia, 1 para normal)
anomaly_predictions = isolation_forest.predict(X_test)
# Converter para 0 (normal) e 1 (anomalia) para comparação com y_test
anomaly_predictions[anomaly_predictions == 1] = 0 # Normal
anomaly_predictions[anomaly_predictions == -1] = 1 # Anomalia

print("\n--- Avaliação do Isolation Forest (Detecção de Anomalias) ---")
print(classification_report(y_test, anomaly_predictions))
print(f"Acurácia: {accuracy_score(y_test, anomaly_predictions):.4f}")

### 3.4.2. Classificação de Falhas com Random Forest
# Modelo supervisionado para classificar se há uma falha ou não.

random_forest_classifier = RandomForestClassifier(n_estimators=100, random_state=42, class_weight='balanced')
random_forest_classifier.fit(X_train, y_train)

# Prever no conjunto de teste
y_pred_rf = random_forest_classifier.predict(X_test)
y_proba_rf = random_forest_classifier.predict_proba(X_test)[:, 1] # Probabilidade da classe 1 (falha)

print("\n--- Avaliação do Random Forest (Classificação de Falhas) ---")
print(classification_report(y_test, y_pred_rf))
print(f"Acurácia: {accuracy_score(y_test, y_pred_rf):.4f}")
print(f"AUC-ROC: {roc_auc_score(y_test, y_proba_rf):.4f}")

## 3.5. Interpretabilidade do Modelo com SHAP
# Entender quais características são mais importantes para a decisão do Random Forest.
# Conforme Ajay Narayanan (2023), "Explainability analysis was then conducted to gain insights into the decision-making process of the fault detection model. This involved the computation of SHAP (SHapley Additi..."

print("\n--- Análise de Interpretabilidade com SHAP ---")
explainer = shap.TreeExplainer(random_forest_classifier)
shap_values = explainer.shap_values(X_test)

# Sumário dos valores SHAP
shap.summary_plot(shap_values, X_test, feature_names=feature_names, plot_type="bar", show=False)
plt.title("Importância das Características (SHAP)")
plt.show()

shap.summary_plot(shap_values[1], X_test, feature_names=feature_names, show=False) # Para a classe 1 (falha)
plt.title("Impacto das Características na Predição de Falha (SHAP)")
plt.show()

print("\nAl IAdo: Pipeline de detecção de falhas concluído. Os gráficos SHAP mostram a influência de cada característica na predição.")
