#### 2. `autoencoder` – Treinamento do Modelo de Normalidade

*   **Propósito:** O Autoencoder (AE) é treinado exclusivamente com dados de operação *saudável* (do dataset Paderborn) para aprender a representação compacta e a reconstrução desses dados. A ideia é que ele terá uma alta "erro de reconstrução" (Reconstruction Error - RE) quando confrontado com dados anômalos, que ele nunca viu durante o treinamento.
*   **Execução:** O AE foi treinado com as 235 mil amostras do dataset Paderborn, operando a 10 kHz.
*   **Resultados:**
    *   **Limiar p99 = 2,91**
    *   **Linha de base μ+3σ = 0,30**
*   **Interpretação:** Aqui temos um ponto interessante, Rodolfo. O limiar p99 (percentil 99 do erro de reconstrução nos dados de treinamento saudáveis) de 2,91 é significativamente maior que a linha de base de μ+3σ (0,30).
    *   **μ+3σ:** Se o erro de reconstrução seguisse uma distribuição normal perfeita, μ+3σ capturaria aproximadamente 99,7% dos dados. O valor de 0,30 sugere que a *média* dos erros é baixa, mas a dispersão ou a presença de alguns "falsos positivos" (pontos com erro de reconstrução mais alto, mas ainda considerados normais) é considerável.
    *   **p99:** O uso do p99 (2,91) é uma abordagem mais robusta para definir o limiar de anomalia em Autoencoders. Ele garante que 99% dos dados *saudáveis* sejam classificados como normais, mesmo que a distribuição do erro de reconstrução não seja perfeitamente gaussiana ou contenha alguns outliers naturais. Isso é crucial para evitar alarmes falsos excessivos.
    *   **Conclusão:** O AE está aprendendo bem a normalidade, e o limiar p99 é uma escolha pragmática e eficaz para a detecção de anomalias, pois se adapta melhor à distribuição real dos erros de reconstrução, que raramente é perfeitamente normal. Isso nos dá uma boa base para identificar desvios. 💡

O valor próximo de 1,0 sugere que o modelo é altamente discriminativo, o que é fundamental para a manutenção preditiva. Estamos conseguindo identificar essas falhas simuladas com alta precisão.

Vamos falar sobre o RUL/Weibull. 📊

O RUL (Remaining Useful Life) é uma técnica utilizada para estimar a vida útil restante de um componente ou sistema. Já a distribuição de Weibull é uma função de probabilidade contínua que é comumente utilizada para modelar a vida útil de componentes e sistemas.

A combinação de RUL e Weibull é uma abordagem poderosa para prever a vida útil restante de um componente ou sistema, considerando a sua história de funcionamento e as condições operacionais atuais.

A distribuição de Weibull é definida pela seguinte equação:

F(t) = 1 - exp(-(t/η)^β)

onde:
- F(t) é a probabilidade de falha do componente em um tempo t
- η é o parâmetro de escala (ou tempo médio entre falhas)
- β é o parâmetro de forma (ou índice de Weibull)

O RUL é calculado utilizando a seguinte equação:

RUL = η \* (1 - (t/η)^β)

onde:
- RUL é a vida útil restante do componente
- t é o tempo atual de funcionamento do componente
- η e β são os parâmetros da distribuição de Weibull

Essa abordagem é útil para prever a vida útil restante de componentes e sistemas, permitindo a realização de manutenção preventiva e reduzindo o risco de falhas inesperadas.
