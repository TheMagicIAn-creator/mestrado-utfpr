## Interacao 2

**Rodolfo:** Faça um código complexo que mostra um gráfico senoidal se mexendo indefinidamente.

**ALIAdo PV:**

Aqui está um script completo em Python usando **NumPy** e **Matplotlib** (com `FuncAnimation`). 

O código constrói uma animação contínua e em tempo real de um sinal senoidal complexo — composto pela superposição de três componentes harmônicas com diferentes frequências e direções de propagação (\(h_1, h_2, h_3\)), moduladas por uma envoltória de baixa frequência.

### Código em Python

```python
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation

# Configuração da figura e temas visuais
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(10, 7), gridspec_kw={'height_ratios': [2, 1]})
fig.patch.set_facecolor('#0f172a')  # Fundo escuro (Slate 900)

for ax in (ax1, ax2):
    ax.set_facecolor('#1e293b')      # Fundo do gráfico (Slate 800)
    ax.tick_params(colors='#94a3b8')
    ax.xaxis.label.set_color('#e2e8f0')
    ax.yaxis.label.set_color('#e2e8f0')
    ax.title.set_color('#f8fafc')
    for spine in ax.spines.values():
        spine.set_color('#475569')

# Domínio espacial (x)
x = np.linspace(0, 4 * np.pi, 1000)

# Grafico 1: Sinal Principal e Envoltória
line_main, = ax1.plot([], [], lw=2.2, color='#38bdf8', label=r'Sinal Composto $y(x,t)$')
line_env_up, = ax1.plot([], [], lw=1.2, ls='--', color='#f43f5e', alpha=0.7, label=r'Envoltória $\pm E(x,t)$')
line_env_dw, = ax1.plot([], [], lw=1.2, ls='--', color='#f43f5e', alpha=0.7)

ax1.set_xlim(0, 4 * np.pi)
ax1.set_ylim(-3.5, 3.5)
ax1.set_ylabel('Amplitude')
ax1.set_title('Superposição e Modulação de Ondas Senoidais', fontsize=12, fontweight='bold')
ax1.grid(True, linestyle=':', alpha=0.3, color='#94a3b8')
ax1.legend(loc='upper right', facecolor='#0f172a', edgecolor='#475569', labelcolor='white')

# Gráfico 2: Harmônicas Individuais
line_h1, = ax2.plot([], [], lw=1.2, color='#a855f7', alpha=0.8, label=r'$h_1(x,t) = 1.2\sin(2x - 1.5t)$')
line_h2, = ax2.plot([], [], lw=1.2, color='#34d399', alpha=0.8, label=r'$h_2(x,t) = 0.8\sin(5x + 2.5t)$')

ax2.set_xlim(0, 4 * np.pi)
ax2.set_ylim(-1.8, 1.8)
ax2.set_xlabel('Posição / Espaço ($x$)')
ax2.set_ylabel('Componentes')
ax2.grid(True, linestyle=':', alpha=0.3, color='#94a3b8')
ax2.legend(loc='upper right', facecolor='#0f172a', edgecolor='#475569', labelcolor='white')

def init():
    """Inicializa linhas vazias para otimizar a renderização (blitting)."""
    line_main.set_data([], [])
    line_env_up.set_data([], [])
    line_env_dw.set_data([], [])
    line_h1.set_data([], [])
    line_h2.set_data([], [])
    return line_main, line_env_up, line_env_dw, line_h1, line_h2

def update(frame):
    """Atualiza a física da onda a cada quadro (frame)."""
    t = frame * 0.04  # Escala temporal
    
    # 1. Harmônicas individuais (frequências e direções distintas)
    h1 = 1.2 * np.sin(2 * x - 1.5 * t)
    h2 = 0.8 * np.sin(5 * x + 2.5 * t)
    h3 = 0.4 * np.sin(9 * x - 4.0 * t)
    
    # 2. Modulação de amplitude (Envoltória de baixa frequência)
    envelope = 1.2 + 0.6 * np.cos(0.5 * x - 0.4 * t)
    
    # 3. Sinal resultante composto
    y_main = (h1 + h2 + h3) * (envelope / 1.5)
    
    # Atualiza gráficos
    line_main.set_data(x, y_main)
    line_env_up.set_data(x, envelope * 1.8)
    line_env_dw.set_data(x, -envelope * 1.8)
    
    line_h1.set_data(x, h1)
    line_h2.set_data(x, h2)
    
    return line_main, line_env_up, line_env_dw, line_h1, line_h2

# Animação contínua (Frames infinitos via gerador `iter(int, 1)`)
ani = FuncAnimation(
    fig, 
    update, 
    frames=iter(int, 1), 
    init_func=init, 
    blit=True, 
    interval=20,          # ~50 FPS
    cache_frame_data=False
)

plt.tight_layout()
plt.show()
```

### O que torna este gráfico "complexo"?

1. **Superposição Harmônica:** O sinal principal não é uma senoide pura, mas a soma de três frequências espaciais e temporais distintas:
   \[
   y_{comp}(x,t) = \left[ 1.2\sin(2x - 1.5t) + 0.8\sin(5x + 2.5t) + 0.4\sin(9x - 4.0t) \right] \cdot M(x,t)
   \]
2. **Ondas Progressivas e Regressivas:** As componentes sobem e descem em direções opostas no espaço (\(-1.5t\) e \(+2.5t\)), gerando padrões de interferência construtiva e destrutiva em tempo real.
3. **Modulação de Amplitudes (\(M(x,t)\)):** Uma envoltória pontilhada em tom rosa/vermelho acompanha a modulação do pacote de onda.
4. **Visualização em Dois Painéis:** O painel superior exibe o sinal modulado final, enquanto o painel inferior isola as duas principais harmônicas constituintes.
5. **Execução Indefinida sem Estouro de Memória:** Usa `cache_frame_data=False` e um gerador infinito no `FuncAnimation`, garantindo que o gráfico rode continuamente por horas sem acumular uso de RAM.

Para rodar, certifique-se de ter `numpy` e `matplotlib` instalados (`pip install numpy matplotlib`).
